# Phase 2: earnings order and the invoice document

Branch `e2e_live`, on top of `844daf7`. 29 Sep 2026. Client-only: the four people tiles move above the chart, and the invoice becomes a real document — one model rendered three ways (dialog preview, print sheet, email HTML) with Download PDF printing the sheet alone.

Captures: [`captures/p2-earnings-invoice/`](../captures/p2-earnings-invoice/) — `p2-earnings-tiles-order.jpg`, `p2-invoice-dialog-sent.jpg` (August, paid), `p2-invoice-print-media.jpg` (what the printer receives: only the sheet).

### r2-p2-01-tiles-order

- `earnings-tab.tsx`: the `SmallTile` grid (Patients seen, New patients, Attendance, Retention) now sits between the KPI cards and the Daily earnings card, wrapped as `data-qc="earnings-tiles"`; hooks unchanged (`earnings-patients`, `earnings-new-patients`, `earnings-attendance`, `earnings-retention`).
- Checked: the tab's block order is stepper row → KPI grid → `earnings-tiles` → `earnings-daily` → `earnings-table`.

### r2-p2-02-invoice-document

- `src/lib/invoice-document.ts` (new, pure, no I/O): `InvoiceDocument` (number, issuedOn, dueOn, from, billTo, periodLabel, qty, amount, note, status), `buildInvoiceDocument()` (period label "1–30 September 2026", due = issued + 14 days unless given), `invoiceMoney`, `invoiceDate` ("1 Oct 2026"), `invoicePeriodRange`, and `invoiceDocumentHtml(doc)` — a self-contained HTML string (inline styles, inline SVG mark, no scripts, no external assets) with the mockup's layout: mark + INVOICE, number, Issued / Due, From / Bill to, the treatments line, Adjustments £0.00, Total due, the note, the footer "Generated by SQINOS from completed treatments in the diary." Notes are HTML-escaped.
- `tests/unit/invoice-document.test.ts`: 4 tests (period and due date, explicit due date, every field present in the HTML, escaping / no scripts).

### r2-p2-03-print-sheet

- `src/components/profile/invoice-sheet.tsx` (new): `InvoiceSheet({ doc })` — the React rendering of the model (hooks `invoice-preview`, `invoice-number`, `invoice-issued`, `invoice-due`, `invoice-from`, `invoice-qty`, `invoice-amount`, `invoice-total`); `InvoicePrintSheet({ doc })` — the same sheet portalled onto `<body>` as `[data-print-sheet]`, `hidden print:block`, mounted only while the dialog is open.
- `printInvoice(doc)` in `profile-helpers.ts`: sets `document.title = doc.number` and `body[data-printing="invoice"]`, calls `window.print()` on the next tick, restores both on `afterprint`. Save as PDF therefore names the file after the invoice number.
- `styles.css` `@media print`: with `body[data-printing="invoice"]`, every direct child of `<body>` except the sheet is hidden and the sheet shown; `print-color-adjust: exact` so the mark and tints print; `@page { size: A4; margin: 14mm }`.

### r2-p2-04-dialog-uses-document

- `invoice-dialog.tsx`: builds `doc` with `buildInvoiceDocument` — a sent or paid month uses the stored number, amount, treatments, `sent_at` and note; an open month uses the live `getMyEarnings` figures, today's / the send date and the note being typed (the preview updates as you type). The right pane renders `InvoiceSheet`; the three Download PDF buttons call `printInvoice(doc)`; `InvoicePrintSheet` is mounted beside the dialog. The hand-rolled preview markup, `moneyExact`, `addDays` and the `BrandMark` import are gone.
