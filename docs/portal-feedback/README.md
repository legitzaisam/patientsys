## Worklog template

Each `worklog/NN-<phase>.md` follows this shape:

```
# Phase N: <name>

Branch, commit hash, date.

## Scope
The bullets covered (numbers from this index), quoted.

## Changes
One entry per bullet or to-do: files touched, what changed and why, migration and demo parity if any.

## Verification
The exact commands run and their results (counts, deltas against the Phase 0 baseline), and which e2e expectations were updated and why.

## Captures
Paths of the screenshots taken for the items (from Phase 5 onwards, using the responsive config).

## Notes
Anything left, any interpretation made, anything for the follow-on phase.
```
